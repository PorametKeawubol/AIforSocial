ใบงาน: การจัดหมวดหมู่ Tag คอร์สเรียน ThaiMOOC ด้วย BERT
วัตถุประสงค์: เพื่อสร้างโมเดลประมวลผลภาษาธรรมชาติ (NLP) สำหรับทำนาย Tag ของคอร์สเรียน ซึ่งสามารถมีได้หลาย Tag ในหนึ่งคอร์ส (Multi-label Classification) โดยใช้ข้อมูลจากชื่อวิชา คำอธิบาย และสถาบัน

ขั้นตอนการแก้ปัญหา (Step-by-Step)

1. การเตรียมข้อมูลและสำรวจข้อมูล (Data Preparation & EDA)
โหลดข้อมูล: นำเข้าไฟล์ train.csv และ test.csv เพื่อดูโครงสร้างข้อมูล
การรวมข้อความ (Text Concatenation): เนื่องจากโมเดล BERT ต้องการบริบทที่ครบถ้วน ควรนำคอลัมน์ title, description และ institute มารวมกันเป็นข้อความเดียวเพื่อให้โมเดลเรียนรู้ความสัมพันธ์ของเนื้อหา
ตัวอย่าง: "ชื่อวิชา: [title] | คำอธิบาย: [description] | สถาบัน: [institute]"
จัดการข้อมูลสูญหาย: ตรวจสอบและจัดการค่าว่างในคอลัมน์ description เพื่อไม่ให้เกิดข้อผิดพลาดขณะ Tokenization
2. การเตรียม Label สำหรับ Multi-label Classification
การแยก Tag: ข้อมูล Tag ในชุดฝึกฝนจะถูกคั่นด้วยเครื่องหมาย "|"
MultiLabelBinarizer: ใช้เทคนิค One-Hot Encoding สำหรับ Label เพื่อเปลี่ยน Tag ข้อความให้เป็นตัวเลข (Vector) เช่น แทนการมี Tag การศึกษาและคอมพิวเตอร์
3. การทำ Tokenization ด้วย BERT
เลือกโมเดล Open Source: เลือกใช้โมเดล BERT  PhayaThaiBERT ที่รองรับภาษาไทย 
Tokenization: ใช้ Tokenizer ของโมเดลที่เลือก เพื่อแปลงข้อความเป็น Input IDs และ Attention Masks โดยต้องกำหนดค่า max_length ให้ครอบคลุมคำอธิบายรายวิชาที่ยาว
4. การสร้างและฝึกฝนโมเดล (Model Architecture & Fine-tuning)
โครงสร้างโมเดล: ใช้สถาปัตยกรรม BertForSequenceClassification โดยปรับเลเยอร์สุดท้าย (Output Layer) ให้มีจำนวนโหนดเท่ากับจำนวน Tag ทั้งหมดที่มีในระบบ
Activation Function: ใช้ Sigmoid แทน Softmax เพื่อรองรับการทำนายหลายหมวดหมู่พร้อมกัน (Multi-label)
Loss Function: ใช้ Binary Cross Entropy with Logits Loss ซึ่งเหมาะสมกับงานประเภทนี้
Fine-tuning: ฝึกฝนโมเดลด้วย train.csv โดยปรับจูน Hyperparameters เช่น Learning Rate และ Epochs
5. การทำนายผลและการสร้างไฟล์ส่งงาน (Inference & Submission)
การทำนาย: นำโมเดลที่ฝึกฝนแล้วไปใช้กับ test.csv
Thresholding: กำหนดค่า Threshold (เช่น 0.5) เพื่อตัดสินใจว่าคอร์สนั้นควรได้รับ Tag ใดบ้างตามค่าความน่าเชื่อถือที่โมเดลส่งออกมา
การรวมผลลัพธ์: แปลงตัวเลขกลับเป็นชื่อ Tag และเชื่อมต่อด้วยเครื่องหมาย "|" หากมีการทำนายได้มากกว่า 1 Tag
สร้างไฟล์ Submission: บันทึกผลลัพธ์ลงในไฟล์ CSV ที่ประกอบด้วยคอลัมน์ index และ tag ตามรูปแบบที่กำหนด
และช่วยทำ ประสิทธิภาพในชุด Test.csv พวก accuracy, precision + recall, f1-score  และอื่นๆ
สรุปคือ 2 อย่าง ไฟล์ CSV และ รายงานประสิทธิภาพของโมเดล

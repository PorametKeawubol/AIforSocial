# Model III — Plant Disease Schema + `GraphDatabase`

## กราฟนี้คืออะไร

Model III ใช้ schema เฉพาะงานโรคพืชจาก `Neo4j_Create.py`: `Crop`, `Disease`, `Pathogen`, `Symptom` และ `Treatment`. Qwen3.5 สกัดข้อมูลเข้า schema ก่อน แล้ว `GraphDatabase` บันทึกลง Neo4j.

## วิธีอ่านกราฟ

- สีเขียว: `Crop` เช่น พริก ข้าวโพด ทุเรียน
- สีแดง: `Disease`
- สีม่วง: `Pathogen`
- สีเหลือง: `Symptom`
- สีน้ำเงิน: `Treatment`

เส้นในกราฟใช้ความหมายตรงตาม schema ได้แก่ `HAS_DISEASE`, `CAUSED_BY`, `EXHIBITS` และ `TREATED_BY`.

## จุดเด่นและข้อจำกัด

จุดเด่นคือโครงสร้างตรงกับคำถามด้านเกษตรและอ่านง่ายที่สุด เช่น “ทุเรียนเป็นโรคอะไร” หรือ “โรคนี้มีอาการและวิธีรักษาอะไร”. ระบบรับข้อมูลเฉพาะเมื่อพบชื่อพืชและชื่อโรคในหน้า PDF เดียวกัน จึงลดการเดา แต่ทำให้กราฟมีขนาดเล็กกว่า Model I และอาจพลาดความรู้ที่อธิบายต่อเนื่องข้ามหน้า.

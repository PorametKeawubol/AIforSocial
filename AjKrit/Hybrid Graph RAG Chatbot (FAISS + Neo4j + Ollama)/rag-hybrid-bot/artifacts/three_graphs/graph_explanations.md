# คำอธิบายกราฟ Neo4j ทั้ง 3 วิธี

## Model I — Neo4jGraph + Qwen3.5

กราฟนี้สร้างจากการให้โมเดลภาษา Qwen3.5 อ่านข้อความในคู่มือและสกัดข้อเท็จจริงแบบมีโครงสร้าง เช่น **พืชเป็นโรคอะไร โรคเกิดจากอะไร มีอาการอย่างไร และรักษาหรือป้องกันอย่างไร** จากนั้นส่งข้อมูลเข้า Neo4j ผ่าน `Neo4jGraph`.

จุดเด่นคือได้ความสัมพันธ์เชิงความหมายของโรคพืช เหมาะกับการใช้เป็นฐานความรู้สำหรับ Graph RAG. อย่างไรก็ตาม ความสัมพันธ์มาจากการสกัดของ LLM จึงควรตรวจหลักฐานและเลขหน้าที่อยู่ในตารางประกอบก่อนนำไปใช้อ้างอิงเชิงวิชาการ.

## Model II — GraphDatabase + ThaiNameTagger

กราฟนี้ใช้ `ThaiNameTagger` ตรวจจับชื่อเฉพาะภาษาไทย เช่น **บุคคล สถานที่ เวลา องค์กร จำนวนเงิน และเปอร์เซ็นต์** แล้วเขียนเข้า Neo4j ด้วย `GraphDatabase`. เส้น `CO_OCCURS_WITH` หมายถึง entity สองรายการปรากฏอยู่ใกล้กันภายในข้อความชุดเดียวกัน.

จุดเด่นคือไม่ต้องพึ่ง LLM ในการหา entity และเห็นองค์ประกอบภาษาไทยในเอกสารได้ชัดเจน แต่เส้นเชื่อมไม่ได้ยืนยันว่า entity ทั้งสองมีความสัมพันธ์ทางเหตุและผล เช่น การพบชื่อบุคคลกับชื่อสถานที่ใน chunk เดียวกันไม่ได้แปลว่าบุคคลนั้นอาศัยอยู่ที่สถานที่นั้น.

## Model III — Plant Disease Schema + GraphDatabase

กราฟนี้ใช้ schema เฉพาะงานโรคพืช ได้แก่ `Crop`, `Disease`, `Pathogen`, `Symptom` และ `Treatment`. ระบบเก็บข้อมูลเฉพาะเมื่อพบชื่อพืชและโรคในหน้า PDF เดียวกัน แล้วบันทึกลง Neo4j ด้วย `GraphDatabase`.

จุดเด่นคือโครงสร้างตรงกับโจทย์โรคพืช อ่านง่าย และเหมาะกับคำถามแบบ “พืชนี้เป็นโรคอะไร” หรือ “โรคนี้มีอาการและวิธีรักษาอะไร” กราฟมีจำนวนน้อยกว่า Model I เพราะใช้กฎตรวจเข้ม เพื่อลดการเดาชื่อพืชหรือโรคจากบริบทข้ามหน้า.

## ความหมายของสีโหนด

| สี | ประเภท | ความหมาย |
|---|---|---|
| เขียว | `Crop` | พืช เช่น พริก ข้าวโพด ทุเรียน |
| แดง | `Disease` | โรคพืช |
| ม่วง | `Pathogen` | เชื้อหรือสาเหตุ เช่น เชื้อรา เชื้อแบคทีเรีย |
| เหลือง | `Symptom` | อาการที่สังเกตได้ |
| น้ำเงิน | `Treatment` | วิธีป้องกันหรือรักษา |
| เทา | `Topic` | หัวข้อความรู้ทั่วไป |

สำหรับ Model II สีแสดงชนิด Named Entity ของ ThaiNameTagger เช่น `PERSON`, `LOCATION`, `TIME` และ `ORGANIZATION`.

## ข้อความสั้นสำหรับใส่สไลด์

“เปรียบเทียบการสร้าง Knowledge Graph 3 แนวทาง: Model I ใช้ LLM สกัดความสัมพันธ์เชิงความหมาย, Model II ใช้ Thai NER เชื่อม entity ที่ปรากฏร่วมกัน, และ Model III ใช้ schema เฉพาะโรคพืชเพื่อให้โครงสร้างตอบคำถามเกษตรได้ตรงประเด็น.”

# Model II — `GraphDatabase` + `ThaiNameTagger`

## กราฟนี้คืออะไร

Model II ใช้ ThaiNameTagger ตรวจจับ Named Entity ภาษาไทยจากข้อความ เช่น บุคคล สถานที่ เวลา องค์กร จำนวนเงิน และเปอร์เซ็นต์ แล้วเขียน node และ edge เข้า Neo4j ด้วย `neo4j.GraphDatabase`.

## วิธีอ่านกราฟ

โหนดแต่ละสีคือประเภท Named Entity ที่ tagger พบ เช่น `PERSON`, `LOCATION`, `TIME` และ `ORGANIZATION`. เส้น `CO_OCCURS_WITH` หมายถึง entity สองรายการปรากฏอยู่ใกล้กันภายใน chunk ข้อความเดียวกัน.

## จุดเด่นและข้อจำกัด

จุดเด่นคือสกัดชื่อเฉพาะภาษาไทยแบบไม่พึ่ง LLM และตรวจผลระดับ token ได้จาก `ner_raw_tokens.json`. อย่างไรก็ตาม `CO_OCCURS_WITH` เป็นเพียงการปรากฏร่วมกัน ไม่ได้ยืนยันความสัมพันธ์จริง เช่น ชื่อบุคคลและสถานที่ที่มีเส้นเชื่อมกันไม่ได้หมายความว่าบุคคลนั้นอาศัยหรือทำงานที่สถานที่นั้น.

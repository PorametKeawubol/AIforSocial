# Model I — `Neo4jGraph` + LLM Extraction

## กราฟนี้คืออะไร

Model I ใช้ Qwen3.5 อ่านข้อความในคู่มือและสกัดความสัมพันธ์เชิงความหมาย จากนั้นเขียนข้อมูลเข้า Neo4j ด้วย `langchain_neo4j.Neo4jGraph`. โหนดในกราฟแทนพืช โรค สาเหตุ อาการ วิธีรักษา และหัวข้อความรู้ทั่วไป.

## วิธีอ่านกราฟ

- `HAS_DISEASE`: พืชมีโรคนั้น
- `CAUSED_BY`: โรคมีสาเหตุจากเชื้อหรือปัจจัยนั้น
- `EXHIBITS`: โรคแสดงอาการนั้น
- `TREATED_BY`: โรคมีวิธีรักษาหรือจัดการนั้น
- `PREVENTED_BY`: วิธีนั้นช่วยป้องกันโรค
- `RELATED_TO`: ข้อความทั้งสองเกี่ยวข้องกัน แต่ไม่จำเป็นต้องเป็นเหตุและผล

## จุดเด่นและข้อจำกัด

จุดเด่นคือเห็นความสัมพันธ์ขององค์ความรู้โรคพืชได้กว้างที่สุด จึงเหมาะกับ Graph RAG. แต่เส้นเชื่อมสกัดจาก LLM จึงต้องใช้คอลัมน์ `evidence` และ `page` ในตารางประกอบเพื่อตรวจกลับไปยัง PDF ทุกครั้ง.

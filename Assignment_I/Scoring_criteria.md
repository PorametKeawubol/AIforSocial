## Key Checkpoints

### 1. Scraping Robustness

ทดสอบความทนทานของระบบ Web Scraping เมื่อข้อมูลหรือโครงสร้างเว็บไซต์ต้นทางไม่เป็นไปตามที่คาดหวัง

สิ่งที่ต้องทดสอบ:

- HTML Structure มีการเปลี่ยนแปลง
- Selector บางส่วนไม่สามารถค้นหา Element ได้
- ข้อมูลบาง Attribute หายไป เช่น ราคา ชื่อสินค้า หรือรูปภาพ
- Request Timeout หรือ Connection Error
- HTTP Response ไม่สำเร็จ
- ระบบสามารถจัดการ Missing Values ได้
- ความผิดพลาดจาก Scraping ต้องไม่ทำให้ระบบทั้งหมด Crash

**Expected Result:** ระบบควรจัดการ Error ได้อย่างเหมาะสม และข้อมูลที่ผิดพลาดบางรายการต้องไม่ทำให้ Data Pipeline ทั้งหมดหยุดทำงาน

---

### 2. NLP Accuracy, Latency & Edge Cases

ทดสอบความสามารถของ NLP ในการวิเคราะห์คำสั่งจากผู้ใช้

**Accuracy Target**

> Intent / Entity Accuracy > **85%**

ควรทดสอบคำสั่งหลายรูปแบบ เช่น:

- คำสั่งพื้นฐาน
- ภาษาพูด
- คำพิมพ์ผิด
- คำสั่งที่มีหลายเงื่อนไข
- คำสั่งที่กำกวม
- คำสั่งที่ไม่มีสินค้า/เงื่อนไขตรงกับฐานข้อมูล

**Latency Target**

> User Command → NLP Processing → Product Retrieval → Response  
> ควรใช้เวลาประมาณ **ไม่เกิน 1.5–2.0 วินาที** ภายใต้สภาพแวดล้อมทดสอบที่กำหนด

ระบบควรมี Fallback Response ที่เหมาะสมเมื่อไม่สามารถตรวจจับ Intent หรือ Entity ได้

---

### 3. Randomization Fairness

ทดสอบการสุ่มสินค้าในกลุ่ม Top 5 เพื่อป้องกันการแสดงสินค้าชุดเดิมซ้ำบ่อยเกินไป

สิ่งที่ต้องตรวจสอบ:

- แสดงสินค้าได้ครบตามจำนวนที่กำหนด
- ไม่มีสินค้าซ้ำภายใน Carousel เดียวกัน
- การ Refresh หลายครั้งไม่ควรได้ชุดสินค้าเดิมตลอด
- ไม่มี Infinite Loop ใน Randomization Logic
- หากจำนวนสินค้าที่ผ่านเงื่อนไขน้อยกว่า 5 รายการ ระบบต้องสามารถจัดการได้อย่างเหมาะสม
- Randomization ต้องไม่ทำลายเงื่อนไขการกรองสินค้าจาก NLP

**Expected Result:** สินค้าที่แสดงควรมีความหลากหลาย โดยยังคงตรงตามเงื่อนไขของผู้ใช้

## Final Scoring

คะแนนของแต่ละด้านให้ประเมินในระดับ **0–5 คะแนน** แล้วคำนวณตามน้ำหนักของแต่ละหมวด

**สูตร**

`Weighted Score = (Rubric Score / 5) × Weight`

ตัวอย่าง:

หาก **NLP Command Processing = 4/5**

`(4 / 5) × 25 = 20 คะแนน`

จากนั้นนำ Weighted Score ของทั้ง 5 หมวดมารวมกัน

> **Final Score = Web Scraping + NLP + Carousel + LINE UX + Code Quality**

**Maximum Score: 100 คะแนน**
